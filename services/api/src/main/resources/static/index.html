Delivery guarantees

Kafka delivery is at least once. Stable event and window IDs make database projections safe to replay. Human review status is preserved on reprocessing.

Deployment

Docker Compose provides a local stack. Kubernetes manifests add health probes, resources and persistent storage. The development Spark deployment runs in a single pod.

Time & quality

A two-minute watermark bounds window state. Invalid source records are quarantined with their Kafka coordinates; unusually future-dated events cannot move the watermark unchecked.
